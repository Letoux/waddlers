# /implement

Implement a bounded Waddlers task.

1. Read CLAUDE.md, AGENTS.md and specs.md.
2. Inspect the current implementation.
3. Read the relevant plan/handoff.
4. Choose frontend or backend implementer.
5. Implement only the assigned scope.
6. Ask the test designer for tests when behavior changes.
7. Run verification.
8. Return a concise handoff.

Do not declare completion without actual verification.
