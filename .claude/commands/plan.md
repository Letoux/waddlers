# /plan

Use the Waddlers planner.

1. Read CLAUDE.md, AGENTS.md and specs.md.
2. Inspect relevant code.
3. Delegate to `waddlers-planner`.
4. If architecture is materially involved, also delegate to `waddlers-architect`.
5. Produce an implementation plan.
6. Do not modify product code.

The plan must include:
- objective;
- relevant requirements;
- files/modules likely affected;
- dependencies;
- risks;
- tests;
- acceptance criteria;
- recommended execution agent.
